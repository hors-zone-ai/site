// 01 · programme de sponsoring · sur candidature

Claude Code ou Codex, payé par l'asso

Pour les devs et les étudiants en informatique qui n'ont pas les moyens de payer ces outils. Tu candidates et, si tu es retenu, l'asso te paie l'un des deux, au choix, à ton nom, pour coder sur nos projets.

au choix · Anthropic

Claude Code

L'assistant de code d'Anthropic, dans ton terminal et ton éditeur.

  • Sur l'abonnement Claude de l'asso, à ton nom
  • Pour coder, corriger et comprendre un projet
  • Pas d'entraînement de modèle sur ton code par défaut

au choix · OpenAI

Codex

L'agent de code d'OpenAI, dans ChatGPT, ton terminal et ton éditeur.

  • Sur l'abonnement ChatGPT de l'asso, à ton nom
  • Pour coder, corriger et comprendre un projet
  • Les mêmes limites d'usage que ChatGPT Plus
  • Toujours un compte à ton nom, jamais partagé.
  • Jamais de revente d'accès : les éditeurs l'interdisent, et nous aussi.
  • Uniquement des abonnements officiels des éditeurs.
  • L'accès sert à construire : il dure le temps de ton travail sur nos projets, puis il passe à quelqu'un d'autre.

Financé par les dons : voir où va l'argent. Programme indépendant de Hors Zone AI. Claude Code est une marque d'Anthropic, Codex une marque d'OpenAI.
